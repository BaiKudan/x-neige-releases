# X内阁桌面安装包

此仓库提供 Windows x64 安装包和自动更新清单。

[下载最新版](https://github.com/BaiKudan/x-neige-releases/releases/latest)

安装 0.14.4 或更高版本后，在设置的更新页开启自动下载。程序启动后检查更新，并每隔 15 分钟再次检查。下载完成后，选择重启安装即可升级。项目、会话和设置保存在用户目录的 `.ao/ao-team` 下。

自动更新清单位于 [latest.yml](https://github.com/BaiKudan/x-neige-releases/releases/latest/download/latest.yml)。每个版本同时提供 SHA256.txt，清单使用 SHA-512 校验安装包。

当前安装器尚未配置 Windows 代码签名。macOS 与 Linux 更新渠道后续单独发布。
